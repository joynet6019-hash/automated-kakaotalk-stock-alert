# Automated KakaoTalk Delivery of Stock Market Prices

한국투자증권 KIS 실전 시세, 카카오톡 나와의 채팅, Supabase 상태 저장과
GitHub Actions 자동화를 연결하는 한국어 구축·운영 매뉴얼입니다.

공개 사이트:

[**Stock Alert**](https://joynet6019-hash.github.io/automated-kakaotalk-stock-alert/#top)

이 공개 저장소에는 정적 문서 파일만 포함되어 있습니다. API 키, OAuth 토큰,
Supabase 서비스 키와 암호화 키는 포함하지 않습니다.
